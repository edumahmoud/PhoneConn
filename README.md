# PhoneConn — مختبر الأمن السيبراني التعليمي 🛡️

منصة ويب تعليمية تفاعلية لمحاكاة سيناريوهات اختبار الاختراق للشبكات اللاسلكية والأجهزة المحمولة
(أندرويد / iOS) في **بيئة افتراضية معزولة 100%** — إضافة إلى **فحص شبكة حقيقي آمن** لاكتشاف
الأجهزة المتصلة بشبكتك فعلياً — بهدف التعليم ونشر الوعي والثقافة الأمنية.

> ⚠️ **تنويه مهم:** المختبرات داخل المنصة **افتراضية بالكامل** ولا تنفذ أي عملية اختراق فعلية.
> وحدة فحص الشبكة الحقيقي استكشافية آمنة فقط (ARP + ICMP + فحص منافذ) تعمل على الشبكة التي يتصل بها الخادم،
> مثل تطبيقات اكتشاف الأجهزة المعروفة (Fing/Nmap -sn) — استخدمها على شبكتك الخاصة أو شبكة مصرح لك باختبارها.
> اختبار أنظمة حقيقية دون تصريح مكتوب يخالف قوانين الجرائم المعلوماتية في معظم الدول.

## الغرض التعليمي

- فهم كيف تعمل هجمات الشبكات اللاسلكية (لماذا WEP مكسور، لماذا كلمات المرور الضعيفة تُكسر رغم قوة التشفير).
- فهم كيف تصل التطبيقات الخبيثة لموارد الهاتف (الكاميرا/الميكروفون/الشاشة/الملفات) وكيف تكشفها مؤشرات النظام.
- إدراك من يستمع على شبكتك المحلية فعلياً عبر فحص ARP/Ping الحقيقي مع شرح آلية اكتشاف الأجهزة (OUI والمنافذ) وكيف تحميها (MAC العشوائي، عزل الشبكات...).
- إدراك حجم البصمة الرقمية عبر تجربة حقيقية مباشرة في وحدة التدقيق الذاتي.
- تدريب المدربين على عرض سيناريوهات الأمن أمام الطلاب والعائلات والفرق ببيئة آمنة.

## التقنيات

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + shadcn/ui (ثيم سيبراني داكن RTL)
- **Zustand** لإدارة حالة الجلسة
- خط **Cairo** العربي + Geist Mono للطرفية

## التشغيل

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # فحص الكود
```

## البنية

```
src/
├── app/                    # الصفحة الرئيسية + API (network/info, network/scan)
├── components/phoneconn/   # وحدات المنصة (فحص حقيقي/شبكات/أجهزة/تدقيق/أكاديمية/تقارير)
├── lib/scanner/            # محرك الفحص الحقيقي (ARP/Ping/Ports/OUI) — للخادم فقط
└── lib/phoneconn/          # البيانات الافتراضية، الأنواع، متجر الحالة
```

### واجهات API للفحص الحقيقي

| المسار | الوظيفة |
|---|---|
| `GET /api/network/info` | معلومات واجهة الشبكة الفعلية للخادم (IP، MAC، النطاق، البوابة، SSID، الأدوات المتاحة) |
| `GET /api/network/scan?force=1` | فحص كامل لنطاق /24: Ping Sweep + ARP + Reverse DNS + 27 منفذاً + تصنيف الأجهزة |

## ميثاق الاستخدام

باستخدام هذه المنصة أنت تتعهد بأن تستخدمها للتعلم والتدريب والتوعية فقط، وأن أي اختبار
لأجهزة أو شبكات حقيقية يتطلب تصريحاً مكتوباً من مالكها. لمسارات مهنية مشروعة راجع
قسم «الحدود الأخلاقية والقانونية» داخل المنصة (شهادات OSCP/CEH، مختبرات Hack The Box
وTryHackMe، برامج Bug Bounty).
