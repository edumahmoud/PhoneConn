# PhoneConn — مركز التواصل مع راوتر شبكتك الحقيقية 🛡️

أداة ويب تعمل بالكامل **من متصفح هاتفك** — بدون أي سيرفر خارجي — للتواصل مع **راوتر الشبكة المحلية
الحقيقية المتصل بهاتفك**: تحديد عنوانه، فتح لوحة التحكم بضغطة واحدة، فهم إعداداته، وتدقيق أمان
شبكتك المنزلية بتدقيق تفاعلي من 10 بنود بدرجة من 100.

> ⚠️ **تنويه:** الأداة مخصصة لراوترك الخاص أو شبكة مصرّح لك صاحبها بإدارتها. الدخول إلى أجهزة لا
> تملكها دون تصريح مكتوب يخالف قوانين الجرائم المعلوماتية في معظم الدول.

## لماذا من متصفح الهاتف وليس من سيرفر؟

سيرفر سحابي لا يستطيع الوصول إلى شبكتك المنزلية — والحماية الأعمق هي أن المتصفحات تمنع صفحات
الإنترنت من قراءة أجهزة شبكتك المحلية (سياسات Mixed Content و Private Network Access). لذلك صُممت
PhoneConn لتعمل **من جهازك أنت**: متصفح هاتفك هو الجسر الوحيد بينك وبين راوترك، وكل شيء يبقى بينكما.

## الميزات

| الخطوة | الوصف | نوعها |
|---|---|---|
| **اتصال هاتفك الحقيقي** | حالة الإنترنت، جودة الاتصال (4G/WiFi، السرعة، زمن الاستجابة)، البطارية، IP المحلي عبر WebRTC مع شرح خصوصية mDNS | حقيقي 🔒 |
| **1 — تحديد الراوتر** | العناوين الأكثر شيوعاً بضغطة، إدخال يدوي بتحقق IPv4، اقتراحات ذكية مستنتجة من عنوان هاتفك المحلي، ودليل مصوّر خطوة بخطوة لأندرويد/iOS/Windows | حقيقي 🔒 |
| **2 — لوحة التحكم** | أزرار وصول مباشرة للوحة تحكم الراوتر عبر العناوين والمنافذ الشائعة (HTTP/HTTPS/8080/8443)، نسخ العنوان، وتأكيد الرابط الذي فتح معك (يُحفظ)، وقائمة "ماذا تفعل داخل اللوحة؟" | حقيقي 🔒 |
| **3 — فحص الكفاءة الفعلي** | قياسات حقيقية تمر عبر الراوتر: زمن استجابة (20 عينة)، اهتزاز Jitter، فقد حزم، سرعة تحميل 8MB ورفع 2MB (عبر Cloudflare مع بديل محلي)، واختبار ازدحام المخازن Bufferbloat (الاستجابة أثناء التحميل مقابل الخمول) → درجة A+..F + تفسير النتائج ونصائح تحسين | حقيقي 🔒 |
| **4 — الاتصال المباشر (وضع محلي)** | اتصال فعلي من الخادم بالراوتر: ping حقيقي، فحص 10 منافذ TCP، قراءة لوحة الإدارة (HTTP banner + عنوان الصفحة)، كشف الشركة من MAC/OUI — يعمل على راوتر بيتك عند تشغيل التطبيق محلياً داخل شبكتك (خطوات بسيطة داخل التطبيق) | حقيقي عند التشغيل المحلي 🔒 |
| **قاعدة معرفة المصنّعين** | 15 شركة (TP-Link، Huawei، ZTE، D-Link، WE، Vodafone، Etisalat، Orange، Netgear، Asus، Linksys، Sagemcom، Xiaomi، Tenda، MikroTik): عناوين الدخول، النطاقات المحلية (tplinkwifi.net...)، بيانات الدخول الافتراضية لتذكيرك بتغييرها، ونصائح أمنية لكل شركة | معرفة عامة 📖 |
| **التدقيق الأمني** | 10 بنود تفاعلية بأوزان (كلمة مرور المدير، WPA2/WPA3، قوة كلمة WiFi، WPS، تحديث النظام، الإدارة عن بُعد، UPnP، شبكة الضيوف، قائمة الأجهزة، DNS) → درجة من 100 + تقدير + أولوياتك القادمة + شرح "كيف أفحص هذا؟" لكل بند + تقرير قابل للطباعة | تفاعلي ✅ |

## الخصوصية

- لا يجمع التطبيق أي بيانات شخصية ولا يحفظ أي شيء على أي سيرفر — سجل الجلسة والحالات في `localStorage` على جهازك.
- فحص الكفاءة يرسل حِزم قياس فقط (طلبات ping صغيرة + 8MB تحميل + 2MB رفع) إلى نقاط قياس عامة (Cloudflare) — بلا أي بيانات عنك.
- فحص «الاتصال المباشر» ينفَّذ من الخادم المضيف للتطبيق: في الاستضافة السحابية يفحص شبكة الاستضافة فقط، وعند تشغيلك للتطبيق محلياً يتصل براوتر بيتك مباشرة (أنت من يشغّله، والبيانات لا تغادر شبكتك).

## التشغيل

```bash
bun install
bun run dev        # ثم افتح المعاينة على هاتفك
```

```bash
bun run build && bun run start   # نسخة الإنتاج
bun run lint                     # فحص الجودة
```

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Zustand · lucide-react

واجهة عربية RTL بثيم سيبراني داكن، متجاوبة بالكامل مع شاشات الهواتف.

## هيكل المشروع

```
src/
├── app/
│   ├── layout.tsx            # RTL + الخطوط العربية (Cairo)
│   ├── page.tsx              # الصفحة الواحدة: مركز الراوتر
│   └── api/
│       ├── ping/             # نقطة قياس الاستجابة (204)
│       ├── speedtest/        # بديل قياس السرعة المحلي (تحميل/رفع)
│       └── router/probe/     # الاتصال المباشر بالراوتر (ping/منافذ/banner/OUI)
├── components/phoneconn/
│   ├── chrome.tsx            # الشريط العلوي + التذييل + اتفاقية الاستخدام
│   ├── router-center.tsx     # حالة الهاتف + تحديد الراوتر + لوحة التحكم
│   ├── router-efficiency.tsx # فحص الكفاءة الفعلي (قياسات حقيقية)
│   ├── router-direct.tsx     # الاتصال المباشر (وضع محلي)
│   ├── router-kb.tsx         # قاعدة معرفة المصنّعين
│   ├── router-audit.tsx      # التدقيق الأمني التفاعلي
│   └── shared.tsx            # عناصر مشتركة (طرفية السجل، الترويسات)
└── lib/phoneconn/
    ├── routers.ts            # بيانات الشركات + بنود التدقيق + أدلة العثور على IP
    ├── efficiency.ts         # محرك القياس في المتصفح (latency/jitter/loss/bloat)
    ├── store.ts              # حالة الجلسة (Zustand)
    └── types.ts              # الأنواع
```

## الاستخدام المفيد

1. افتح التطبيق من **هاتفك المتصل بشبكتك المنزلية**.
2. حدد عنوان راوترك (أو اتبع دليل "كيف أجده؟").
3. افتح لوحة التحكم وسجّل الدخول (البيانات على ملصق الراوتر).
4. راجع إعدادات الأمان حسب قائمة "ماذا تفعل داخل اللوحة؟".
5. أخضع نفسك للتدقيق التفاعلي وشارك التقرير المطبوع مع من يدير الراوتر.
