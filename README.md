# PhoneConn — مختبر الأمن السيبراني التعليمي المحاكى 🛡️

منصة ويب تعليمية تفاعلية لمحاكاة سيناريوهات اختبار الاختراق للشبكات اللاسلكية والأجهزة المحمولة
(أندرويد / iOS) في **بيئة افتراضية معزولة 100%** — بهدف التعليم ونشر الوعي والثقافة الأمنية.

> ⚠️ **تنويه مهم:** جميع الشبكات والأجهزة والثغرات داخل المنصة **افتراضية بالكامل** وتعيش داخل المتصفح.
> لا تتصل المنصة بأي شبكة أو جهاز حقيقي، ولا تنفذ أي عملية اختراق فعلية.
> اختبار أنظمة حقيقية دون تصريح مكتوب يخالف قوانين الجرائم المعلوماتية في معظم الدول.

## الوحدات

| الوحدة | الوصف | نوعها |
|---|---|---|
| **لوحة القيادة** | نظرة عامة، إحصائيات الجلسة، والميثاق الأخلاقي | — |
| **مختبر الشبكات** | فحص شبكات وهمية (WEP/WPA/WPA2/WPA3/Open)، التقاط المصافحة الرباعية، هجوم القاموس، محاكاة Deauth، تحليل نقاط الضعف | محاكاة |
| **مختبر الأجهزة** | أجهزة أندرويد/iOS افتراضية بشاشة حية: سيناريوهات تصيّد، تطبيق خبيث، كاميرا، انعكاس شاشة، وصول ملفات، مؤشرات الخصوصية | محاكاة |
| **التدقيق الذاتي** | فحص **حقيقي وآمن** لجهاز المستخدم بموافقته: ماذا يرى أي موقع عنك تلقائياً (User-Agent، الشاشة، البطارية، الأذونات، WebRTC Leak، بصمة Canvas...) | حقيقي 🔒 |
| **أكاديمية الوعي** | 6 دروس مركزة + اختبار وعي أمني من 8 أسئلة بتفسيرات علمية | — |
| **التقارير** | تقرير جلسة تعليمية بهيكل احترافي + توزيع الخطورة + توصيات + تصدير PDF | — |

## الغرض التعليمي

- فهم كيف تعمل هجمات الشبكات اللاسلكية (لماذا WEP مكسور، لماذا كلمات المرور الضعيفة تُكسر رغم قوة التشفير).
- فهم كيف تصل التطبيقات الخبيثة لموارد الهاتف (الكاميرا/الميكروفون/الشاشة/الملفات) وكيف تكشفها مؤشرات النظام.
- إدران حجم البصمة الرقمية عبر تجربة حقيقية مباشرة في وحدة التدقيق الذاتي.
- تدريب المدربين على عرض سيناريوهات الأمن أمام الطلاب والعائلات والفرق ببيئة آمنة.

## التقنيات

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + shadcn/ui (ثيم سيبراني داكن RTL)
- **Zustand** لإدارة حالة الجلسة
- خط **Cairo** العربي + Geist Mono للطرفية

## التشغيل

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # فحص الكود
```
